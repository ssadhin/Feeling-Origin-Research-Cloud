# CoSpine ds005883 pre-outcome plan mirror

The pre-outcome frozen protocol is Google Doc ID 1SZnO_4YFMUKcHE-PmAhcabDrZ1bxcFimpRHsA3AWPR0. This GitHub file was committed AFTER inspecting event data; it is an archival mirror, not an independently time-stamped preregistration.

Dataset README reports separate PR intensity and UpR unpleasantness for 39 people. Before outcome access, prediction: nonzero within-person UpR residual after PR and heat control. Failure if missing, unpairable, constant or collinear.

Future OOD model comparison: sorted subject IDs, every fifth held out. B0 = PR, heat, trial index; B1 = B0 + physiology; B2 = B1 + sensory ROI; candidate = B2 + independently defined cingulate-insula coupling. Positive benchmark held-out delta R2 >= 0.05, subject-bootstrap lower 95% bound >0, permutation p<0.05. A positive observational predictor is not causal proof.

P (phenomenal presence) remains distinct from S (affective significance), and neither is identified with valuation, sensory intensity, autonomic response, reporting, access or reasoning. Ownership is not required; old ownership-dependent equation rejected. Kill if sensory/physiology/attention/report rivals explain the effect, held-out or independent replication fails, or double causal dissociation fails. Report is fallible evidence of experience, not strict third-person proof.

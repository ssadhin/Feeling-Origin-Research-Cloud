00_CANONICAL — TOURNAMENT–MIST RESEARCH METHOD v1.0
Date: 2026-10-07
Paper program: Artificial Emotion Simulation
Status: CANONICAL WORKING METHOD
Parent method sources: project's Recursive Option Tournament, MIST, Emergent Emotion adversarial loop, and external research-methodology audit.
PURPOSE
Build the strongest defensible research workflow for discovering and testing artificial-emotion mechanisms without rewarding emotional appearance, selecting a favorite theory too early, or confusing a formally easy pattern with a specific mechanism.
CLAIM LIMIT
This method is not claimed to be universally "the best methodology in the world." No scientific procedure can be proven globally optimal across every question. This protocol is designed to be the strongest justified stack for THIS class of formal/computational artificial-emotion research, and it must itself remain open to adversarial revision.
CORE IDEA
Two original project methods are combined:
1. RECURSIVE OPTION TOURNAMENT
Generate -> formalize -> attack -> categorize -> compare -> regenerate -> repeat to saturation.
2. MIST
For each formal survivor, quantify how cheaply/generically it can be implemented across declared minimal systems, including prevalence, minimal realizations, equivalence/symmetry, controls and robustness.
These are augmented by:
systematic evidence audit;
preregistration/Registered-Report logic;
adversarial collaboration logic;
optimal experimental design;
causal interventions and negative controls;
model recovery;
global sensitivity analysis;
multiverse/specification-curve analysis;
equivalence testing;
metamorphic software testing;
cross-environment/architecture replication;
full computational provenance.
==================================================
I. THREE NESTED LOOPS
==================================================
OUTER LOOP — DISCOVERY TOURNAMENT
Purpose:
Do not stop at the first plausible model.
Sequence:
GENERATE
-> FORMALIZE
-> HARD-CHECK
-> CATEGORIZE / EQUIVALENCE-GROUP
-> COMPARE
-> REGENERATE
-> repeat.
Output:
a changing population of candidate mechanisms and explicit failed rivals.
MIDDLE LOOP — DISCRIMINATION
Purpose:
Find the experiment/intervention that maximally separates surviving models.
Sequence:
derive rival predictions;
run model-recovery simulations;
search experimental design space;
choose high-information intervention/environment;
freeze success/kill criteria;
execute;
update candidate weights/status.
INNER LOOP — SPECIFICITY / ROBUSTNESS
Purpose:
Prevent a winner from surviving merely because it is easy, generic, fragile, or coded incorrectly.
Sequence:
software property checks;
positive/negative controls;
MIST;
parameter sensitivity;
analysis multiverse;
equivalence/null tests;
held-out replication;
OOD transfer.
The result of any inner/middle failure is fed back into the OUTER LOOP as information that can create a new candidate.
==================================================
II. STAGE 0 — LOAD AND FREEZE CURRENT STATE
==================================================
Before new work:
read canonical method;
read current status;
read current candidate map/register;
read failure ledger;
read latest frozen equations/definitions;
read current paper claim ceiling;
check running/frozen confirmatory jobs.
Never silently change a definition, threshold, metric, seed set, or research question.
Any legitimate definition change creates a new candidate/version.
==================================================
III. STAGE 1 — QUESTION + CLAIM LADDER
==================================================
Each loop asks ONE decision question.
Artificial-emotion claim ladder:
AE0 — BEHAVIORAL RESEMBLANCE
Agent behaves in a way humans might label emotional.
Insufficient for mechanism.
AE1 — ENDOGENOUS INTERNAL STATE
A reproducible internal organization covaries with relevant conditions beyond direct input/output mapping.
AE2 — MULTI-SYSTEM COORDINATION
The state coordinates at least two independently measured downstream systems such as attention, memory, learning rate, exploration, action selection, resource allocation, social policy, or prediction.
AE3 — CAUSAL REGULATOR
Intervening on the candidate internal organization changes multiple downstream processes in the prespecified direction.
AE4 — SPECIFIC NONTRIVIAL MECHANISM
AE3 survives:
simple reward/reflex baselines;
flattened/generic mimics;
negative controls;
MIST;
model recovery;
parameter/analysis robustness.
AE5 — GENERALIZABLE ARTIFICIAL EMOTION MECHANISM
AE4 transfers across held-out environments and at least one materially different implementation/architecture where the theoretical claim predicts transfer.
AE6 — BIOLOGICALLY COHERENT GENERAL MECHANISM CANDIDATE
AE5 makes successful, nontrivial correspondences/predictions against relevant biological/behavioral evidence not used to construct the mechanism.
NO AE0–AE6 CLAIM ESTABLISHES SUBJECTIVE FEELING OR CONSCIOUSNESS.
==================================================
IV. STAGE 2 — SYSTEMATIC EVIDENCE / PRIOR-ART AUDIT
==================================================
Before expensive simulation:
search current literature using a logged, reproducible protocol.
For each candidate:
search exact name;
mechanistic synonyms;
mathematical equivalents;
older terminology;
adjacent disciplines;
known rival theories;
negative/null evidence;
citation chains;
recent reviews.
Record:
query;
database/source;
date;
paper/version;
DOI;
peer-reviewed/preprint status;
what exact claim it supports/contradicts;
access limitation;
include/exclude reason.
Use PRISMA-style transparent screening/reporting principles where applicable.
NOVELTY RULE
"Not found" means only:
not found within the documented search.
Never "nobody has ever proposed this."
==================================================
V. STAGE 3 — GENERATE THE OPTION UNIVERSE
==================================================
Use at least these generation operators:
A. established theory family;
B. negation of current leader;
C. simplest rival;
D. mechanistic decomposition;
E. merge complementary survivors;
F. split overloaded variable;
G. reverse causal direction;
H. add bypass path;
I. add hidden/common cause;
J. learned vs innate/prepared split;
K. state vs process vs disposition reinterpretation;
L. centralized vs distributed implementation;
M. categorical vs dimensional form;
N. deterministic vs stochastic form;
O. reactive vs predictive form;
P. model-free vs model-based control;
Q. local vs global coordination;
R. one-timescale vs hierarchical-timescale;
S. residual-driven candidate from unexplained observations;
T. candidate generated from a failed model's exact failure.
Every candidate receives a permanent ID.
Where the space is finite, enumerate it exhaustively.
Where the space is open-ended, iterate until the convergence rules in Stage 15 are satisfied.
==================================================
VI. STAGE 4 — ATOMIC FORMALIZATION
==================================================
For EACH candidate freeze:
1. exact verbal mechanism;
2. ontological/computational type;
3. variables/state space;
4. equations/state transitions where possible;
5. causal graph;
6. allowed inputs;
7. predicted internal signatures;
8. predicted behavioral signatures;
9. positive control;
10. negative control;
11. strongest simpler rival;
12. kill condition;
13. refinement rule;
14. claim ceiling.
No variable may be named "fear", "anger", "sadness", etc. and then used to claim emotion emergence.
Emotion labels may be applied only after the mechanism is characterized, and only as interpretation.
==================================================
VII. STAGE 5 — SOFTWARE VALIDITY BEFORE SCIENCE
==================================================
Before interpreting simulator results:
UNIT / INVARIANT TESTS
Check conservation/constraint rules, boundaries, rewards, state updates, timing, reset logic and randomization.
METAMORPHIC TESTS
Examples:
renaming irrelevant labels must not change results;
permuting symmetric agents/components must preserve symmetric predictions;
adding an unused variable must not generate an effect;
equivalent state encodings must produce equivalent outcomes;
changing time units must preserve dimensionless predictions;
duplicating representational channels must not falsely inflate "coordination";
turning off the proposed mechanism must remove its direct code path.
MODEL RECOVERY TEST
Generate synthetic data from each candidate and confirm the analysis pipeline can recover the generating candidate across realistic noise/seed variation.
FAILURE HERE BLOCKS ALL SCIENTIFIC CLAIMS.
==================================================
VIII. STAGE 6 — MIST SPECIFICITY STRESS TEST
==================================================
For every formal emotion criterion or internal-state signature that can be evaluated in a minimal model class:
DECLARE:
minimal model class S;
criterion Q;
operationalization;
symmetry/equivalence relation;
control class.
COMPUTE WHERE FEASIBLE:
prevalence P(Q|S);
minimal satisfying implementation;
distribution of scores;
symmetry/equivalence classes;
matched-mechanism controls;
noise/perturbation robustness;
overlap with simpler constructs;
collapse motifs / degenerate maxima.
INTERPRETATION
High prevalence or trivial minimal realizations do NOT automatically falsify a mechanism.
They reduce its implementation specificity and force stronger discriminators.
MIST NEVER establishes phenomenality.
==================================================
IX. STAGE 7 — STRONGEST-RIVAL / ADVERSARIAL GATE
==================================================
For each leading candidate, write the strongest version of at least:
1. leader;
2. best mechanistic rival;
3. cheapest/generic rival;
4. behavior-mimic rival;
5. null/no-emotion model.
For each pair:
state a test that defenders of BOTH would accept as discriminating.
If available, use a genuinely independent critic/collaborator.
If not, preserve the limitation and run an internal adversarial review with separate proponent/opponent writeups.
A candidate cannot win by defeating a caricature.
==================================================
X. STAGE 8 — OPTIMAL DISCRIMINATING EXPERIMENT DESIGN
==================================================
Do not choose environments/interventions because they "look emotional."
Given survivors M_1...M_k:
derive predictive distributions under candidate experimental designs d.
Choose high-information designs using a criterion such as:
d* = argmax_d E_y[InformationGain(Model ; y | d)]
or a prespecified model-recovery/discrimination utility.
IMPORTANT ANTI-OVERFIT RULE
Reserve at least one ADVERSARIAL/OOD environment not used in design optimization.
The optimized experiment separates known rivals.
The reserved environment tests whether the whole candidate set was too narrow.
==================================================
XI. STAGE 9 — PRECOMMITMENT FIREWALL
==================================================
Before decisive confirmatory runs freeze:
primary hypothesis;
primary metric;
secondary metrics;
seed list or seed-generation rule;
environment list/generator;
hyperparameter policy;
data exclusions;
stopping rule;
positive/negative controls;
ablation set;

success gate;
partial gate;
kill gate;
model-selection rule;
analysis specifications;
allowed deviations.
Exploration remains allowed but must be labeled EXPLORATORY and cannot silently replace confirmatory tests.
For a strong paper, consider Registered Report submission if a suitable venue exists.
==================================================
XII. STAGE 10 — CAUSAL INTERVENTION TOURNAMENT
==================================================
Behavior alone cannot support AE3+.
For candidate internal organization Z:
A. ABLATE
Remove Z/mechanism while preserving matched capacity where possible.
B. CLAMP
Force Z high/low independently of its normal inputs.
C. SCRAMBLE
Destroy temporal/component organization while preserving marginal statistics.
D. SUBSTITUTE
Replace Z with a simpler scalar/reward/reflex controller matched on performance.
E. BYPASS
Allow downstream behavior without Z to test whether Z is necessary.
F. INJECT
Introduce Z-like organization without original eliciting condition to test sufficiency within scope.
G. NEGATIVE CONTROL
Intervene on a matched variable that should not produce the hypothesized coordinated downstream effect.
H. POSITIVE CONTROL
Use a manipulation known to change the measured downstream system.
A mechanism claim requires the predicted intervention pattern, not mere correlation.
==================================================
XIII. STAGE 11 — ROBUSTNESS WAR
==================================================
A. GLOBAL PARAMETER SENSITIVITY
Use Morris/Sobol-style or suitable global methods.
Ask whether conclusions survive parameter space rather than one tuned point.
B. STRUCTURAL SENSITIVITY
Vary model architecture and structural assumptions, not only numeric parameters.
C. MULTIVERSE / SPECIFICATION CURVE
Run all prespecified justified nonredundant analysis choices:
aggregation;
normalization;
time window;
latent-state extraction;
exclusion rules;
seed summary;
statistical model;
metric variants.
D. EQUIVALENCE TESTING
When claiming "no meaningful difference" or "mechanism not needed", test against a prespecified SESOI/equivalence region.
A nonsignificant difference is not enough.
E. MEASUREMENT ROBUSTNESS
Use multiple independent operationalizations when feasible.
A candidate should not exist only under one metric that directly encodes its definition.

XVI. STAGE 14 — PAPER-SPECIFIC ARTIFICIAL EMOTION TOURNAMENT
==================================================
Minimum mandatory comparator set:
C0 — random / no adaptive control.
C1 — reflex controller.
C2 — scalar-reward RL.
C3 — homeostatic RL / viability controller without emotion-organization mechanism.
C4 — appraisal-like controller without persistent multisystem coordination.
C5 — memory/history controller.
C6 — arousal/global-gain controller.
C7 — our candidate functional emotion organization.
C8 — flattened mimic matched on parameter count/behavioral capacity.
C9 — candidate with coordination mechanism scrambled/ablated.
Additional rivals are generated by the Tournament.
Primary question:
Does C7 develop an endogenous, persistent, multi-system coordination state with causal downstream effects that cannot be reduced to reward, reflex, arousal, memory, generic control capacity, or implementation artifacts?
==================================================
XVII. STAGE 15 — CONVERGENCE / STOPPING RULE
==================================================
The research may stop a discovery cycle only when:
1. every declared finite option space is exhausted;
2. major relevant theory families are represented or excluded with reason;
3. two consecutive regeneration rounds produce no new materially non-equivalent survivor;
4. all surviving candidates are pairwise compared;
5. plausible survivor combinations and simpler collapses are tested;
6. unresolved residuals are explicitly listed;
7. model-recovery/identifiability limits are characterized;
8. new literature searches stop changing the option taxonomy;
9. MIST/sensitivity/multiverse attacks stop generating new viable mechanisms;
10. OOD/adversarial tests do not expose an unmodeled major rival;
11. remaining indistinguishable candidates are labeled UNDERDETERMINED rather than arbitrarily ranked.
Stopping is allowed because of:
CONVERGENCE
or
FORMAL UNDERDETERMINATION.
Stopping is NOT allowed because one model merely looks best so far.

XIX. WHY THIS HYBRID IS STRONGER THAN EITHER ORIGINAL METHOD
==================================================
Tournament alone can find sophisticated candidates but may select a mechanism that is structurally cheap, analytically fragile, or coded incorrectly.
MIST alone can expose cheap implementations but cannot ensure that the right candidate universe was generated or that decisive experiments were chosen.
The hybrid adds independent defenses:
Systematic evidence audit protects candidate coverage.
Precommitment protects against moving goals.
Adversarial-rival testing protects against weak baselines.
Optimal design increases model discrimination.
Causal interventions protect against correlational claims.
MIST protects implementation specificity.
Model recovery protects identifiability.
Sensitivity/multiverse protects robustness.
Equivalence testing makes null claims meaningful.
Metamorphic testing protects software correctness.
Replication/OOD protects generalization.
Provenance protects reproducibility.

XX. METHOD SELF-ATTACK
==================================================
This method itself has possible failure modes:
1. TOO EXPENSIVE
Mitigation:
use staged gates. Cheap conceptual/prior-art/software failures kill candidates before expensive simulation.
2. OPTION EXPLOSION
Mitigation:
equivalence grouping, subtype grouping, atomic pruning, and information-gain prioritization.
3. BUREAUCRACY WITHOUT INFORMATION
Mitigation:
every gate must state which error class it prevents. Remove steps that repeatedly add no decision value.
4. KNOWN-MODEL OVERFITTING
Mitigation:
reserved OOD/adversarial environments and residual-based candidate generation.
5. INTERNAL RED TEAM IS NOT INDEPENDENT
Mitigation:
seek external review/adversarial collaboration before major publication claims.
6. MIST CAN FAVOR COMPLEXITY
Mitigation:
interpret minimal implementation as specificity evidence, not a complexity requirement.
7. FORMALISM CAN OUTRUN CONSTRUCT VALIDITY
Mitigation:
keep construct-validation and biological correspondence separate from mathematical elegance.
8. SIMULATION CAN PROVE ONLY ITS OWN RULES
Mitigation:
state claim ceiling explicitly; AE6 requires external/biological correspondence.
==================================================
XXI. METHOD-OF-METHODS REVISION RULE
==================================================
The Tournament–MIST protocol is itself a candidate.
After every major paper loop ask:
Which gate changed a scientific decision?
Which gate caught an error?
Which gate was redundant?
Which new methodological literature offers a nonredundant protection?
Any proposed method change must:
1. define the failure mode it solves;
2. compare OLD vs PROPOSED;
3. test whether it duplicates an existing gate;
4. run a small pilot where feasible;
5. preserve a migration record.

FINAL METHOD STATEMENT
For Artificial Emotion Simulation, the canonical workflow is:
SYSTEMATIC MAP
-> RECURSIVE TOURNAMENT
-> FORMALIZE
-> SOFTWARE VERIFY
-> MIST
-> ADVERSARIAL RIVALS
-> MODEL RECOVERY
-> OPTIMAL EXPERIMENT
-> PRECOMMIT
-> CAUSAL INTERVENTION
-> ROBUSTNESS WAR
-> OOD / REPLICATION
-> COMPARE + REGENERATE
-> CONVERGENCE
-> PAPER CLAIM.
The method is designed so that a result must survive multiple DIFFERENT kinds of failure tests rather than simply accumulating confirming evidence.

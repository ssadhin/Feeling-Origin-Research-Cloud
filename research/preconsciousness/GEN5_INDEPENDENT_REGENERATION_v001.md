GENERATION 5 — INDEPENDENT REGENERATION / BOUNDARY PASS v001
Date: 2026-10-07
Program: Pre-Consciousness Construct Separation
PURPOSE
Provide the second consecutive regeneration pass required by the protocol. This pass does not start from the Generation-4 categories. Instead it asks whether classic theory architectures, boundary cases, linguistic uses, developmental cases, and minimal/maximal reductions force a new top-level construct type.
==================================================
1. CLASSIC BODY-FIRST THEORY
==================================================
Option:
Bodily/physiological change precedes and constitutes emotional feeling.
Mapping:
physiological/interoceptive state -> F_emotional or emotion episode.
Result:
New causal ordering, not a new ontological type.
Already representable using body/interoceptive representation, ECE and F^(c).
==================================================
2. PARALLEL CENTRAL/BODY THEORY
==================================================
Option:
A central eliciting process generates bodily response and conscious experience in parallel.
Mapping:
latent/common cause -> physiology and F/E outputs.
Result:
Already represented by latent-common-cause/latent-state architecture.
==================================================
3. TWO-FACTOR / AROUSAL + INTERPRETATION THEORY
==================================================
Option:
Arousal plus contextual/cognitive interpretation yields emotion experience/category.
Mapping:
A + appraisal/conceptualization -> E/F.
Result:
Already represented by constructionist/appraisal architectures.
No new type.
==================================================
4. FACIAL/BODILY FEEDBACK
==================================================
Option:
Expression/action/body feedback contributes causally to later affect/feeling.
Result:
Adds feedback edges from expression/action/body to E/F.
Strengthens recurrence; no new type.
==================================================
5. SOMATIC-MARKER / BODY-VALUATION SIGNAL
==================================================
Option:
Body-linked value signals bias decisions and experienced significance.
Mapping:
interoceptive representation + valuation -> decision/action and possible feeling.
Result:
Fits regulation/representation/valuation/experience types.
==================================================
6. REWARD WANTING / LIKING DISSOCIATION
==================================================
Option:
Motivational incentive salience and hedonic pleasure are separable.
Result:
Requires D/reward-motivation and F_hedonic/valence to remain distinct.
This strengthens, rather than alters, the typed lattice.
==================================================
7. TRAIT / DISPOSITIONAL EMOTION
==================================================
Option:
Stable anxiety, affective style, temperament, personality-like emotion dispositions.
Result:
Trait/disposition is a valid ontological type already in the type register.
It must not be confused with an occurrent emotion episode.
No new type.
==================================================
8. LINGUISTIC "I FEEL THAT..." USE
==================================================
Option:
"Feeling" used as weak belief/opinion/judgment.
Result:
This is a linguistic extension and not sufficient evidence for a phenomenal feeling construct.
Map to cognition/judgment/report, not F_phen.
No new phenomenal type.
==================================================
9. AESTHETIC / MORAL / SOCIAL FEELINGS
==================================================
Examples:
awe, elevation, guilt, shame, belonging, compassion, moral unease.
Result:
These enlarge F^(c) and E/social-relational subtypes but do not introduce a new ontological role.
==================================================
10. SLEEP / CIRCADIAN / FATIGUE / DROWSINESS
==================================================
Result:
Circadian and sleep-wake regulation are additional regulatory/state systems; fatigue/drowsiness can be bodily/affective feelings.
They demonstrate again that the four original words are not exhaustive.
They map to regulatory state + content-indexed F.
==================================================
11. STRESS / ALLOSTATIC LOAD
==================================================
Result:
Stress can be physiological regulation, prolonged affective state, appraisal pattern, and felt experience depending usage.
This is a multi-level word and therefore confirms the need for the ontology/mechanism/measurement separation.
No new top-level type.
==================================================
12. UNCONSCIOUS AFFECT / NONREPORTABLE PROCESSING
==================================================
Option:
Valenced or emotion-relevant processing without report or explicit awareness.
Result:
Further separates functional affective processing from F_phen and from access/report.
No new type.
==================================================
13. DEVELOPMENTAL BOUNDARY CASE
==================================================
Option:
Species-typical action appears only after substantial normal developmental interaction.
Result:
Rejects birth/experience-free definitions of instinct and strengthens canalization/developmental-attractor accounts.
No new top-level type.
==================================================
14. SIMPLE ORGANISM / NON-NERVOUS-SYSTEM CASE
==================================================
Option:
Living systems exhibit regulation and adaptive response without nervous-system emotion/feeling constructs.
Result:
Supports separation of M_C/M_R from prepared neural action, ECE and F.
No new type.
==================================================
15. ARTIFICIAL AGENT CASE
==================================================
Option:
An artificial controller can implement viability regulation, policy priors, motivation-like variables and coordinated internal states without establishing phenomenality.
Result:
Shows formal/functional realization of M/P/E-like roles does not by itself identify F_phen.
Strengthens the phenomenal bridge firewall.
==================================================
16. MINIMAL MODEL OPERATION
==================================================
Attempt:
Collapse V, M_C, M_R, D, P, ECE, F and Access into the smallest number of variables.
Result:
Collapses fail for distinct reasons:
V is a criterion rather than mechanism.
M_C and M_R can differ mechanistically.
D can vary while prepared policy architecture is unchanged.
ECE can be represented as component coordination without being a policy disposition.
F can dissociate from report/access by definition and evidence.
Therefore a one- or two-variable collapse loses discriminating structure.
==================================================
17. MAXIMAL MODEL OPERATION
==================================================
Attempt:
Treat every named construct as a unique fundamental category.
Result:
Over-fragments the system because many are subtypes, dimensions, mechanisms, measurements or alternative formalisms rather than independent natural kinds.
Categorization/equivalence grouping is necessary.
==================================================
18. LATENT-COMMON-CAUSE OPERATION
==================================================
Attempt:
Explain all target correlations by one latent "organismic significance" variable.
Result:
Too broad.
History-dependent significance, valuation or relevance can be unconscious and cannot by itself define feeling.
It also does not distinguish regulatory, action, emotional-episode and phenomenal roles.
==================================================
19. SINGLE-DIMENSION OPERATION
==================================================
Attempt:
Use only valence, only arousal, only survival probability, only prediction error, or only control error.
Result:
Each captures important variance but fails to reconstruct the full heterogeneity of action architecture, emotional episodes and feeling families.
No single scalar survives as the universal common variable.
==================================================
20. SECOND-PASS OUTPUT
==================================================
This independent pass generated:
new subtypes;
new feedback directions;
new context variables;
new examples of trait/state and function/experience separation.
It generated NO NEW TOP-LEVEL ONTOLOGICAL ROLE outside the Generation-4 set:
constraint/criterion;
constitutive/regulatory process;
disposition/program;
motivational/dimensional state;
representation/model;
dynamical episode/trajectory;
phenomenal state/property;
access/measurement.
It generated NO new candidate that forces restoration of a universal Self-maintenance -> Instinct -> Emotion -> Feeling chain.
It generated NO evidence that broad instinct is unitary or that feeling has one known proximal generator.

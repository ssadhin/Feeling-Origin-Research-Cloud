# External arousal replication feasibility audit v001

Date: 2026-10-05

## K-EmoCon
Park et al., Scientific Data 2020. Dataset DOI records include 10.5281/zenodo.3814370 and 10.5281/zenodo.3931963.
- 32 participants in 16 paired debates.
- Participants annotated their own arousal and valence every 5 seconds while reviewing the debate recording.
- Peripheral signals include BVP, EDA, HR/IBI and ECG-derived heart rate.
- Scientifically suitable for a dense self-report arousal replication.
- Dataset files require approved access, so the analysis is not currently executable.

## EMAP
Data DOI 10.5281/zenodo.8327283.
- 145 participants.
- Continuous subjective arousal with HR, respiration, skin conductance, blood volume and EEG.
- Strong arousal-only replication candidate.
- Dataset requires approved academic/research access, so the analysis is not currently executable.

## Other screened datasets
- RECOLA uses continuous external-rater affect labels rather than participants' own momentary feelings.
- Emognition has rich physiology but dimensional self-reports are post-clip rather than dense trajectories.
- Several common emotion datasets similarly use post-trial ratings.
- egoEMOTION appears promising but requires an institutional data-use agreement.

## Decision
Current independent replication is VALENCE ONLY.
Do not imply POPANE externally replicates arousal.

Manuscript scope:
- CASE supports valence and arousal internally.
- POPANE independently replicates the valence benchmark.
- Independent dense-self-report arousal replication remains a limitation and future validation target.

If suitable arousal data access becomes available later, freeze the replication protocol before outcome inspection.
